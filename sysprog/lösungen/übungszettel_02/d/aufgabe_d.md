# Aufgabe 3 d

Beim aufrufen von call springt das programm and die adresse des labels und führt dort das programm weiter aus. Dabei wird auf dem stack gespeichert von welcher adresse aus die Funktion aufgerufen wurde. Außerdem werden einige register auf dem steck gerettet. Wenn ret aufgerufen wird werden die gespeicherten register wiederhergestellt und das programm spring zurück and die gemerkte addresse.
 Auf dem stack werden außerdem parameter und lokale variablen für die Funktion gespeicher.
